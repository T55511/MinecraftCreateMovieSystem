【プロジェクト名】
マイクラ動画制作支援アプリ（Minecraft Create Movie System）

【目的】
・YouTube向けマイクラ動画制作を効率化
・企画〜投稿までを「プロジェクト＋サブタスク」で継続運用できる形にする
・将来：AI（Gemini 2.5 Flash）で台本／構成／サムネ案／振り返り支援

【想定ユーザー】
・自分（単一ユーザ、ローカル運用）

【現状の実装済み機能】
・プロジェクト作成/一覧
・サブタスク管理（Kanban＋Table、D&Dでステータス移動）
・進捗率の自動計算（サブタスク状態から算出）
・チェックリスト（未完了だと完了にできない：409）
・タイマー（開始/停止→TimerLog保存→実績集計へ反映）
・週間負荷（直近7日：実績 vs 見積）
・Dashboard＆全ページ共通サイドバー（週間負荷表示、停止時に即時更新）

【技術構成】
・Backend: Python 3.12 / FastAPI / SQLAlchemy
・Frontend: Next.js 15(App Router) / TS / Tailwind
・DB: PostgreSQL（Docker）
・その他: Docker Compose、将来AI API連携

【現在の進捗】
・Docker起動で基本動作OK
・主要機能（チェックリスト、タイマー、週間負荷、サイドバー表示）まで実装済み
・今後：UI/UX改善、管理画面、テンプレ/マスタ、カレンダー、AI連携フェーズ

【設計方針】
・単一ユーザ/ローカル優先、拡張余地は残す、段階実装、複雑化しすぎない
